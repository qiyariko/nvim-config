#### Requirements

base packages: 

* git

* neovim

* tree-sitter-cli

* gcc (for treesitter-cli)

* xclip

lsp packages:

* rust-analyzer & rust-src

* lua-language-server

* bash-language-sever

* clangd 

#### Getting Started

Clone the repo:

```shell

git clone https://github.com/qiyariko/nvim-config ~/.config/nvim

```

Remove the .git folder:

```shell

rm -rf ~/.config/nvim/.git

```

Start nvim:

```shell

nvim

```
